# Финансы ДНТ — автономная сборка

Эта версия работает без PHP, MySQL и файла config. Все изменения сохраняются локально в браузере устройства.

## Первый запуск
1. Разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте сайт и перейдите в раздел «Настройки» → «Загрузить».
3. Выберите свой `dnt_backup_*.json` с телефона.
4. Подтвердите замену данных.

**Важно:** файл резервной копии содержит персональные данные. Не добавляйте его в GitHub и не размещайте в публичной папке сайта. Выбирайте его только через кнопку импорта внутри приложения.

## Резервное копирование
Регулярно используйте «Настройки» → «Сохранить». Файл хранится у вас и может быть импортирован обратно.

## Ограничения
- Автономная сборка не синхронизируется с сервером и другими устройствами.
- Данные сохраняются в хранилище браузера этого устройства. Не очищайте данные сайта/браузера.
- При восстановлении основного сервера потребуется отдельно перенести новые записи обратно через экспорт/импорт, если серверная версия поддерживает импорт.
- `config`, `api.php` и пароли в эту сборку не включены.
